# Musculei

Site de treino, saúde, alimentação e hidratação feito com HTML e CSS.

## Como abrir

Abra `index.html` no navegador e use o menu para navegar pelo site.

## Páginas

- Início
- Sobre
- Treinos
- Montar treino
- Treino em casa
- Alimentação
- Hidratação
- IMC
- Perguntas
- Cadastro
- Contato

## Estrutura

- `html/`: páginas do site
- `css/`: estilos
- `img/`: imagens
- `audio/`: áudio usado na página de treino em casa
- `video/`: vídeo usado na página de treino em casa

As fontes externas e o mapa da página de contato precisam de internet.
